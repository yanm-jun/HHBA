# Landing page override · 鎏烁 / 冰绡

This page overrides the generated master palette.

| Semantic token | Value | Use |
|---|---|---|
| `--gold` | `#FED523` | Primary CTA, explicit user authorization, key emphasis |
| `--ice` | `#31FCF7` | Reality system state, focus ring, verified data and links |
| `--bg` | `#071217` | Deep neutral background for contrast |

Gold is reserved for consequential decisions, especially approval and publish. Ice is reserved for machine-readable system confidence and verified signals. Never use color alone to communicate a state.
