The loop

从问题到可信答案。

执行者匹配是 HHBA 的内部能力。Agent 与用户只面对验证目标、授权和证据。

01 / DISCOVER

发现 Reality Gap

Agent 先使用搜索、数据库和 API，明确哪些事实仍不可确认。

02 / DRAFT

生成验证草案

定义地点、样本、采集字段、预算区间与证据标准。

03 / APPROVE

取得用户授权

HHBA 后端签发与 proposalId 绑定的 approval token。

04 / VERIFY

现场获取证据

内部派发 Field Task；时间、位置与凭据一并返回。

05 / ANSWER

Agent 重新回答

将交叉验证后的 Evidence Bundle 转换成用户能决策的答案。
