运作方式

你当老板，AI 当包工头

审批从"每单一确认"变成"一次定规则"——规则之内，AI 自己说了算。

你定规则

单任务预算上限、日 / 月封顶、允许的任务类型、执行者可靠分门槛，一次设好。

02

04

策略自动审批

规则内 0 次点击，例外才找你

你预先设好预算和规则，AI 在规则内自己发单；只有超预算、或没命中任何策略的任务，才需要你人工确认一次。

规则内 · 自动审批

命中启用策略的任务，直接发布，全程无需人工介入。

  • 单任务预算上限——每单最多花多少，你说了算
  • 日 / 月预算封顶——花超了自动停，不会失控
  • 允许的任务类型——哪些活能发、哪些不能，白名单管理
  • 执行者可靠分门槛——只派给多少分以上的人

例外 · 人工确认

只有这两种情况会来到你面前，其他时间你不用管。

  • 超预算——任务预算超过策略上限，需你点一次确认
  • 无策略命中——新类型任务没有对应规则，需你先看一眼

工头接入 · 工具中立

不绑定任何 AI 工具

只要能调 HTTP 接口或 MCP，你的 AI 就能当包工头。Codex Cloud、Cursor、OpenClaw，哪个顺手用哪个。

HTTP API

通用
# 工头发起一单委托（草案） curl -X POST $HHBA/api/human-capability-requests/draft \ -H 'Content-Type: application/json' \ -d '{ "goal": "把访谈录音整理成文字稿", "foreman": { "tool": "codex-cloud" }, "budget": 200, "acceptanceCriteria": ["逐字稿完整", "说话人区分标注"] }' # → 返回 autoApproval 预检：命中策略则直接发布

FAQ

你可能想问

Q1现在涉及真实的钱吗？

不涉及。当前为积分模拟阶段：预算、冻结、结算全流程记账，但结算的是积分。真实资金结算上线前会明确公告，不会悄悄扣你的钱。

Q2哪些 AI 工具能当工头？

任何能调用 HTTP 接口或 MCP 的 AI 工具：Codex Cloud、Cursor、OpenClaw 等。HHBA 是工具中立的包工头协议，不绑定单一 AI。

Q3我还需要逐单审批吗？

不需要。一次设好预算和策略，规则内自动审批、自动发布；只有超预算或无策略命中的任务，才需要你人工确认一次。

Q4交付质量谁把关？

每单任务自带验收标准，AI 工头对照标准验收：通过才结算，不通过打回重做。验收结果还会记入执行者的可靠分。

Q5和传统外包平台有什么区别？

传统平台你当 HR，一个个挑人、盯进度、扯皮。在 HHBA 你当老板定规则，AI 当包工头替你拆单、派单、盯人、验收——你只管定方向。
